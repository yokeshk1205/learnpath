# LearnPath

A structured learning path tracker and roadmap tool.

## Features
- Track learning goals and milestones
- Visualize progress across topics
- Export/import roadmaps

## Getting Started
1. Clone the repo
2. Install dependencies (see `/docs/setup.md`)
3. Run the app

## Tech Stack
- Backend: Python/FastAPI
- Frontend: React/Next.js (planned)
- Data: SQLite/PostgreSQL
